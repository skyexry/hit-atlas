# Archived Spotify Visualization Data and Coverage

This page documents the archived Spotify prototype. The current project uses the U.S. Billboard Year-End Hot 100. [Current project](https://github.com/skyexry/hit-atlas#hit-atlas)

The Spotify corpus contains 2,963 project songs. Global charts for 2017–2026 contain 500 positions. The 2024–2026 global subset contains 150 positions and the regional same-window sample contains 3,450. These denominators count chart positions, so the same song may appear more than once.

| Available field | Corpus | Global 2017–2026 | Global 2024–2026 | Regional 2024–2026 |
| --- | ---: | ---: | ---: | ---: |
| Default lyric | 2,950 | 500 | 150 | 3,439 |
| Metadata-checked lyric | 1,707 | 202 | 58 | 1,877 |
| Eight lexical emotion scores | 2,799 | 482 | 142 | 3,291 |
| Archived core audio | 2,397 | 489 | 139 | 2,784 |
| ReccoBeats-only audio for comparison | 2,251 | 432 | 136 | 2,738 |

The 2026 Spotify global ranking estimates observed streams from 45 weekly Top 200 charts through November 12. Regional same-window lists sum observed daily-chart streams from January 1 through November 12 for each year. These chart definitions are specific to the Spotify archive.
