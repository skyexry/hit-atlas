# Archived Spotify Chart Audit

This page documents the archived Spotify prototype. The current project uses the U.S. Billboard Year-End Hot 100. [Current project](https://github.com/skyexry/hit-atlas#hit-atlas)

The November 23, 2026 audit checked seven source CSVs and their audit workbook. Complete lists in the audit had positions 1–50 and a title and artist at each position. Recording identity and source credits require separate metadata checks. See [field sources](../../docs/data-field-sources.md) for the follow-up checks and [coverage](../../docs/visualization-data.md) for the chart windows.
