# Archived Spotify Chart Fields and Song Metrics

This page documents the archived Spotify prototype. The current project uses the U.S. Billboard Year-End Hot 100. [Current project](https://github.com/skyexry/hit-atlas#hit-atlas)

A chart detail row is one position in a market and year, with a rank, title, credited artist, source ID and URL, and the observed window where available. The Global Top 50 table is a filtered chart view. Use the [song and lyric tables](歌曲与歌词/使用说明.md) for recording-level joins and the [field reference](../docs/data-field-sources.md) for provenance.
