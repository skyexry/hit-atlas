# Spotify 热门歌曲项目 · 基础字段与歌曲指标

当前 CSV 记录哪些歌曲上榜。可用的歌曲、歌词与音乐表见[表结构和连接键](歌曲与歌词/使用说明.md)。以下是分析字段的设计，示例数值用于解释公式。第一版优先做原语歌词主题、情绪用词和歌词重复度，声音特征与乐评按实际覆盖增补。

## 1. 已有字段

| CSV | 每行代表什么 | 实际字段 |
|---|---|---|
| 榜单明细.csv | 一个市场某年榜单中的一个位置 | year, market, position, track_title, artist_credit, analysis_set, record_status, market_scope, chart_id, spotify_track_id, id_provenance, source_type, source_url, observed_weekly_top200_streams, window_start, window_end |
| 全球年度趋势Top50_2017-2026.csv | 上表中一个全球榜位置，每年 50 首 | 与榜单明细相同。此表是筛选视图，合并统计时使用其中一份 |
| 地区同期Top50_2024-2026.csv | 一个市场、一个同期累计榜的位置 | year, market, position, track_title, artist_credit, observed_daily_chart_streams, chart_entries, window_start, window_end, observed_days, source_url, in_three_year_panel |
| 地区年份入口.csv | 一个可选的市场、年份和榜单口径 | market, market_zh, year, chart_type, chart_label, source_type, track_count, position_min, position_max, data_file, window_start, window_end, in_three_year_comparison |
| 地区日榜覆盖核验.csv | 一个市场某年的档案覆盖情况 | year, market, expected_days, observed_days, min_daily_entries, max_daily_entries, days_with_rank_gaps, duplicate_positions, complete, in_three_year_panel |
| 榜单来源.csv | 某张榜单的一项来源 | chart_id, year, market, source_type, source_title, source_version, source_url, supporting_url, documented_positions, detail_rows, note |

`year` 是上榜年，`market` 是听众市场，`position` 的含义随榜单口径而定。地区同期榜按每年 1 月 1 日至 11 月 12 日的日榜在榜播放量累计排序。`chart_entries` 是该曲名与署名组合的上榜记录条数，`observed_days` 是整个市场的观测天数。全球 2026 使用 1 月 2 日至 11 月 12 日的 45 个完整周榜。历史歌单保留来源曲序，缺少播放数的位置留空。

## 2. 给榜单接上歌曲特征

数据通过两个编号连接。榜位与录音特征用 `song_id`，逐行歌词及歌词分析用 `lyrics_version_id`。当前[歌曲母表](歌曲与歌词/歌曲母表.csv)保存默认选用的歌词版本。歌曲的歌词匹配状态记录在[歌词匹配](歌曲与歌词/歌词匹配.csv)。

| 分析结果 | 连接字段 | 结果示例 |
|---|---|---|
| 歌词级指标 | lyrics_version_id、method_version | topic_id、topic_label、embedding_ref、emotion_counts、repeat_lz_ratio |
| 逐词贡献 | line_id、token_index、method_version | 词形、情绪类别、贡献值 |
| [音乐特征](音乐特征/song_audio_features.csv) | song_id、matched_spotify_id | tempo_bpm、energy、danceability、audio_valence 及数据来源 |
| 乐评（可选） | song_id、review_id | review_url、review_scope、arrangement_note |

歌词候选可以在 LRCLIB 按曲名、艺人、专辑和时长查询。有同步歌词时去除时间戳并保留实际行序。记录文本来源、录音匹配和使用范围。Zenodo 的 LFM2b 已发布数据只纳入英文歌词，适合对重叠英文曲目的指标进行方法对照。[LRCLIB 文档](https://lrclib.net/docs) · [LFM2b 数据说明](https://zenodo.org/records/7740045)

## 3. 指标计算

**主题与语义近邻。** 语义近邻已用多语言 MiniLM 模型处理原语唱词。固定版本、分块方法、384 维向量及近邻计算见[语义相似度](../analysis/theme/README.md#歌词语义相似度)。主题试跑使用固定题材定义、候选证据行与独立证据复核，状态与覆盖另见[可视化数据清单](../docs/visualization-data.md)。

**情绪用词。** 使用 NRC EmoLex 的八类关联。先对整首歌词识别主语种，再用主语种逐行分词。令 N 为所有字母词次，C_e 为命中某类的词次，H 为词典中存在对应词条的词次。每次出现可分别命中多类。统一方法、位置与空值规则见[情绪计算说明](../analysis/emotion/README.md)。

| 字段 | 计算 | 可回答的问题 |
|---|---|---|
| joy_rate, sadness_rate, anger_rate, fear_rate, disgust_rate, surprise_rate, trust_rate, anticipation_rate | 各自为 100 × C_e / N | 每百词中有几次与某类情绪相关的用词。八项可以重叠 |
| lex_coverage | H / N | 词典对该语种这首歌的覆盖。满足出分条件且某类命中为零时，该类记录 0 |
| repeat_lz_ratio | 1 − Lempel–Ziv 有效压缩字节 / 原文 UTF‑8 字节 | 按 The Pudding 的规则计算整首歌词的压缩降幅。检测范围包括重复词、词组和整段。 |
| chorus_line_share（可选） | 副歌行数 / 已知段落类型的演唱行数；另存分段标注行数 / 总行数 | 明确标注的段落中，多少演唱行属于副歌。仅有“副歌 × 2”而无可核实展开方式的文本标记待核 |
| duration_ms, tempo_bpm | 导入匹配录音的时长与节拍速度。若从可用音频提取 BPM，固定节拍检测方法，复核半速／倍速歧义 | 歌变长还是变短，节拍变快还是变慢 |
| energy, danceability, audio_valence（可选） | 读取同一来源、同一定义的录音级评分，保留来源。跨来源先验证可比性 | 听感强度、舞动感、声音正向感的分布；与歌词指标分别呈现 |
| arrangement_note（个案） | 从明确谈及该录音的制作署名或乐评记录具体配器、音色、段落变化，附证据链接；前奏长度可由核实的音频时间点相减 | 哪一段进入鼓机、合成器或吉他，有什么听觉作用 |

“悲伤相关词频”衡量措辞。若研究问题是“叙述者整体在表达什么情绪”，另设 context_emotion_label，先由能读原语的两人按统一标准标注完整歌词或段落，再验证分类器。可把它保留给精选曲目，前期不需要训练模型。乐评人的感受、歌词叙述者的感受、听众的实际感受应分别标明对象。

## 4. 多语言与汇总

1. 歌词保留原语，先按完整段落识别语言，短行结合相邻行复核。fastText 可给出候选；把最终语言、各语言明确行数、混合行数、待判行数分别记录。语言占比使用明确标注行数及其分母；标记纯器乐曲。听众市场和歌词语言是两个独立字段。[fastText 语言识别说明](https://fasttext.cc/docs/en/language-identification.html)
2. 主题和语义近邻处理原语歌词。按语言和年份分层报告主题判定的待判比例与有效样本量。对语义近邻另外检查结果是否集中在同一语言或同一艺人。机器译文可用于读者释义，保留翻译来源。
3. 当前情绪结果使用整份歌词的主语种词表。NRC 的多语种词表由英文自动翻译，俚语、否定、反讽和混合语都可能影响命中。比较不同市场时优先在共同语种内看词次率，并显示词典覆盖。[NRC EmoLex 翻译说明](https://saifmohammad.com/WebPages/NRC-Emotion-Lexicon.htm)
4. 重复率在保留全部演唱行的原文上计算。比较前检查各语言、各来源的分行习惯、副歌是否完整展开。同一组主题、情绪、重复指标可各有独立的可用状态。
5. 每个市场、年份、榜单类型单独汇总，默认每首歌等权。主题占比 = 该主题有效歌曲数 / 有主题结果的歌曲数；情绪和重复指标先算每首歌，再求组内均值或中位数。每图附“有效曲数 / 50”，并单列未获取、纯器乐、方法待验证。三年地区趋势默认筛选 19 个共同市场。2026 全球年内估计在同一时间轴标注截止日。年度歌单与同期累计榜分别统计。
