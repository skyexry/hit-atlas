# Archived Spotify Audio Features

This page documents the archived Spotify prototype. The current project uses the U.S. Billboard Year-End Hot 100. [Current project](https://github.com/skyexry/hit-atlas#hit-atlas)

[Audio features](song_audio_features.csv) contain one matched recording per `song_id`. `matched_spotify_id` identifies the recording connected to the audio record. For chart positions aggregated by title and credit, retain the recording-link status to show which recording supplies the features.

## Coverage

The archived mixed-source table has 2,397 matched songs. The archived Spotify visualizations use the [2,251-song ReccoBeats-only table](../../analysis/song_audio_reccobeats.csv) for feature comparisons. Tempo is in BPM and loudness is in dB. The field reference documents archive priority and numeric coverage. [Field sources](../../docs/data-field-sources.md) and [coverage by chart](../../docs/visualization-data.md).
