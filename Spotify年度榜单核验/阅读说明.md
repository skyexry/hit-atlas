# Archived Spotify Year-End Chart Source Index

This page documents the archived Spotify prototype. The current project uses the U.S. Billboard Year-End Hot 100. [Current project](https://github.com/skyexry/hit-atlas#hit-atlas)

The November 23, 2026 reference covers Spotify listening markets. The source index used 237 places listed by Spotify plus its global chart. Historical availability varies by year. The archive contains 2,296 track rows over 110 market–year combinations. Of those rows, 291 have no track ID in the selected source. The source register identifies the evidence used for each chart.
