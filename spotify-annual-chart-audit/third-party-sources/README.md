# Archived Spotify Chart Supplemental Sources

This page documents the archived Spotify prototype. The current project uses the U.S. Billboard Year-End Hot 100. [Current project](https://github.com/skyexry/hit-atlas#hit-atlas)

The November 23, 2026 audit assembled 450 global playlist positions for 2017–2025. It checked the first five tracks for 2017–2022 and the first ten for 2023–2025 against published Spotify lists. The source position records the order of the underlying playlist or export. Regional historical stream totals use a separate chart-observation definition. Return to the [chart source index](../README.md) for the release scope.
